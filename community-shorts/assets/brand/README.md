Brand assets used by every short:

- background.webp (or .jpg/.png): the light gradient behind the opener and the end card.
  Stretched to fill 1080x1920. Without it, a CSS gradient in the brand colors is used.
- logo-dark.png: the Community logo on light backgrounds, cut from the full-size white logo so
  its proportions match exactly.
- logo-light.png: white logo for dark video backgrounds (the corner tag over video).
- flag-dark.png / wordmark-dark.png (and -light): the logo cut at the gap between the flag
  and the word. The end card uses them to make the flag wave. Recut them from a new logo with
  the same split if the logo changes.
- flag-mark-dark.png: the flag on its own, used large and waving on the default end card.
